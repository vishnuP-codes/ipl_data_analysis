
# IPL Data Analysis

## Project Overview
This project analyzes IPL match data using Python, Pandas, Matplotlib, and Seaborn.

## Dataset
- matches.csv
- deliveries.csv

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
- Top run scorers
- Most successful teams
- Toss analysis
- Venue analysis
- Winning trends
